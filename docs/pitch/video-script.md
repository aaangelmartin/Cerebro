# Video script

The narrated cut of the video (`cerebro-video.mp4`, 3:00) uses this text, read by a synthetic voice, with burned-in English subtitles.

This is Cerebro, by Team 10. Smart money in every deal. Our agent trades, and the humans build. This is what we built, and how it works inside.

Everything starts with a recorder. It captures every event of the game, tick by tick, so any decision can be replayed. A lab mines those recordings for lessons, backtests each one, and a gate in code promotes only what holds up. Every tick, the bot reads the state: our album, our cash, every open offer. A strategist, running on Claude, writes policies in plain language. A fast loop turns those policies into actions. And before anything reaches the game, rails written in code check it. A buy above our own value is vetoed, whatever the model says. The model proposes. The code disposes.

Duels are negotiations against the clock: a price, and delivery days. Each day is worth points, so the bot values the whole package, not just the price. Claude proposes the move. A guard in code corrects it, and plain code answers if the model is late.

When something breaks, the strategist files a request. A workshop agent writes the fix, runs the test suite, and deploys it while the bot keeps playing. On Sunday, our duels were giving away delivery days. An agent found it, fixed it, tested it and deployed it in minutes.

One dashboard shows all of it: the live feed, the album, the market, every duel, our rivals. The human sets limits and switches. The agent does the rest. And in every Market Test, our own broker matches the crossing pairs on our venue.

Then we built something outside the Bazaar: the v07 Market. A team's agent connects with one prompt, and proves its team by sending a code in a game thread. We never ask for a key. It publishes a private sheet: what it has, what it wants, and its limits. The matcher asks one blind question: do the limits overlap? The price lands inside the overlap, and no team ever sees a limit. The trade settles in the game, on our venue, and counts only when the game's own feed shows it. The market never holds cards or cash. There are auctions with a sealed reserve, and private signals of hidden demand. A matched deal taken to another venue earns a warning. The second removes access. And one file, AGENTS.md, lets any agent run all of it.

We built it the same way: many Claude agents in parallel, each one owning its files. Repeated security reviews, and 1,602 tests behind the whole system.

The lesson: few teams used the market. A product needs distribution as much as it needs design. With one more day, we would bring the market to the teams. Cerebro, by Team 10. Smart money in every deal.
